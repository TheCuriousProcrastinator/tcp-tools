# TCP Tools

Landing page for free downloadable tools from The Curious Procrastinator.

## Local preview

Open `index.html` directly, or serve the folder:

```sh
python3 -m http.server 8888
```

## Deployment

This is a static Netlify site. The requested Netlify subdomain is `tcp.netlify.app`.

Replace the placeholder GitHub URLs and ZIP files when the three tools are ready.
